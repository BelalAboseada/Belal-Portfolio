BELAL ABOSEADA — VISUAL IDENTITY V2.0
=====================================
Developer by day, creator by night.

WHAT THIS IS
------------
The identity system built around the approved B monogram, using only the
Flax Smoke ramp from the site's global.css plus black and white.
There is no red and no other hue anywhere in the system.

The mark itself is unchanged — it was redrawn as clean vector from the
approved artwork, so every file here scales without loss.

MARK RULES
----------
  CLEAR SPACE    X on all four sides, where X is the stem width
                 of the mark (0.205 × cap height).
  MINIMUM SIZE   Mark 24 px / 8 mm. Lockup 88 px.
  PROPORTIONS    Width 0.860 H · Stem 0.205 H · Top bar 0.179 H
                 Aperture 0.114 H · Fold angle 36.3° · Grid H/14
  NEVER          Stretch, rotate, add colour, outline, add effects
                 to, or crowd the mark. Never upscale a PNG.
